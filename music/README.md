# music

The first Java-8-compatible multitrack renderer for 3d4j. The original experimental source is preserved as `src/main/java/MultiTrackMusicRenderer.java`, so the earlier JAR can be rebuilt instead of being checked in as an opaque binary.

The input is the TSV format generated by `experiments/kipitz-gemma-multitrack.ps1`. Call `gradle :music:jar` and run the script in the same PowerShell session that defines `$ApiKey` and `$CompletionsUrl`.

Render without an API call:

```sh
gradle :music:renderDemo
```

Listen to `music/build/demo-output/arrangement.wav`; open `arrangement.mid` in a MIDI editor. Per-track WAV files (`melody`, `harmony`, `bass`, `drums`) are also exported.

## Gemma retry and harmonic normalization

The PowerShell experiment stores every successful model response in `%TEMP%\\kipitz-gemma-multitrack`. On a later run it **reuses** those files instead of requesting expensive already-finished parts again. Add `-Regenerate` to regenerate all steps deliberately.

The model sometimes produces a non-chord pitch (e.g. MIDI 48/C over G in the bass). The standalone music script picks the nearest legal triad note in the requested instrument range, logging each correction to `harmonic-corrections.txt`. Original responses (`bass.json`, etc.) are never overwritten by normalization. Other invalid timing or malformed model output is still rejected.

The offline regression tests are in `experiments/test-harmonic-pitch.ps1`; they test both saved-file execution and the same code evaluated as an interactive PowerShell script block.

The music script is **self-contained**: it does not dot-source another file. You can execute the saved `.ps1` file or paste its complete contents into a PowerShell session. For the pasted case, the script uses the fixed [latest release](https://github.com/aresstack/audio/releases/tag/latest) to download `music-renderer.jar` to `%TEMP%\\aresstack-audio-renderers` once; running as a saved repo script prefers `music/build/libs/music-renderer.jar`. Successful Gemma JSON outputs are reused from `%TEMP%\\kipitz-gemma-multitrack` on restart, even if no API key is available. To test only the pitch logic, run the saved script with `-SelfTest`.
